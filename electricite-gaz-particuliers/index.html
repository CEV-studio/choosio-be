GUIDE ÉNERGIE

Faire le point sur votre énergie à la maison

Votre lieu de fourniture, les énergies utilisées et votre consommation permettent de préparer une étude adaptée à votre logement.

Quelles informations préparer ?

Une facture annuelle peut vous aider à retrouver votre consommation et votre fournisseur actuel. Si vous ne les avez pas, vous pouvez commencer votre demande et les préciser plus tard.

Votre compteur et vos panneaux solaires

Le type de compteur et, le cas échéant, votre installation photovoltaïque peuvent influencer l’étude. Précisez leur situation si vous la connaissez ; les règles et les frais dépendent des conditions applicables.

Comment fonctionne Choosio ?

Choosio prépare un service de mise en relation pour l’étude des contrats d’énergie. Le formulaire est une démonstration : aucune demande n’est transmise et aucun classement automatique des offres n’est affiché.

Pour aller plus loin : consulter les informations du service public et des organismes de régulation.

Quels critères regarder au-delà du prix ?

Comparez l’estimation annuelle avec les mêmes consommations, la redevance, la durée et les conditions tarifaires. Pour un tarif variable, consultez la formule d’indexation ; pour un tarif fixe, vérifiez la durée pendant laquelle le prix concerné reste fixe.

Les offres et les coûts de réseau dépendent notamment du lieu de fourniture. Pour les panneaux solaires, examinez séparément les conditions liées à l’électricité prélevée et, le cas échéant, injectée.

Où trouver son code EAN ?

Le code EAN identifie le point de fourniture et figure généralement sur la facture. Il existe un code distinct pour chaque point d’électricité ou de gaz. Consultez notre guide pour lire votre facture d’énergie.
